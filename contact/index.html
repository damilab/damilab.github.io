SlotGCG (ICLR 2026)
Trustworthy AI

신뢰할 수 있는 AI

AI가 실제 현장에서 쓰이려면 성능만큼 신뢰가 중요합니다. 공정성, 견고성, 프라이버시와 보안, 해석 가능성을 중심으로 안전하고 윤리적인 AI를 만드는 방법을 연구합니다.

진행 연구

  • 다국어 LLM 탈옥 가드레일 구축
  • GUI 에이전트 보안 취약점과 방어
  • Embodied 로봇 에이전트 안전성 평가
  • 가정용 로봇의 VLM 기반 위험 완화

관련 논문

  • SlotGCGICLR 2026
  • ReCAREICLR 2026
  • Will the User Ever Know?EMNLP 2026
  • Confess What You KnowEMNLP 2026
SafeBranch (EMNLP 2026 Findings)
Physical AI

피지컬 AI

AI가 화면 밖으로 나와 실제 세계에서 움직이려면 보고, 계획하고, 행동할 수 있어야 합니다. VLM과 VLA 기반 로봇이 복잡한 과업을 스스로 계획하고 수행하는 방법을 연구합니다.

진행 연구

  • 멀티로봇 협업
  • 안전한 가정용 로봇 planning
  • 피지컬 AI 학습용 데이터 생성

PLCWorld (arXiv 2026)
LLM Data & Agents

LLM 데이터 생성과 에이전트

LLM을 산업 현장에 쓰려면 그 분야에 맞는 데이터와 평가 기준이 먼저 필요합니다. LLM을 학습시키고 평가할 데이터를 만들고, 제조, 블록체인, 금융 같은 실제 도메인의 문제를 푸는 LLM 에이전트를 연구합니다.

진행 연구

  • LLM 생성 PLC 프로그램 검증 벤치마크
  • LLM 멀티 에이전트 블록체인 분석
  • LLM 에이전트 금융 전략 탐색
